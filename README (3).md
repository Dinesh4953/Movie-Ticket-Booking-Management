# Movie Ticket Booking Management

## Overview
A Pega-based application for managing movie ticket booking requests.

## Main Case Type
Movie Ticket Request

## Workflow
Request Intake → Availability Check → Customer Review → Booking Execution → Confirmation → Resolution

## Data Objects
- Movie
- Show
- Ticket
- Seat
- Customer
- Venue
- Premium Show Queue
- Standard Show Queue
- Booking Notification

## Key Features
- Submit movie ticket requests
- Check show and seat availability
- Calculate booking cost
- Confirm or cancel booking
- Process ticket booking
- Send booking confirmation
- SLA management
- Route Premium and Standard shows to appropriate queues

## Technology
- Pega Infinity 25.1.3
- Pega App Studio
- Pega Dev Studio
